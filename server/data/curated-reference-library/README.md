# Curated Reference Library

This is SiteSynth's starter seed for visual and product reference selection.

Principles:
- `competitor_site` and `product_reference` drive UX, IA, flows, and component patterns.
- `visual_gallery` drives visual direction only.
- `internal_curated` is the quality anchor and should be preferred when its market fit is close.

Fields:
- `product_types`: high-level archetypes like `saas`, `fintech`, `mobile_app`, `marketplace`
- `surface_types`: where the reference is useful, e.g. `marketing`, `dashboard`, `search`, `listing`
- `selection_bias`: how to weight the reference in shortlist generation
- `capture_targets`: pages we should try to screenshot first

This file is intentionally small. Start with 20-30 strong references, then expand from real briefs and reviewed discoveries.
