# Настройка CompanyInfo для AI Chat

Эта таблица хранит **публичную информацию о компании**, которой AI чат будет делиться с клиентами.

## Шаг 1: Создайте таблицу в NocoBase

1. Откройте http://138.2.134.17:20000
2. Создайте новую таблицу **CompanyInfo**
3. Добавьте эти колонки:

| Колонка | Тип | Описание |
|---------|-----|---------|
| `id` | Number (ID) | Auto-increment |
| `key` | Single Line Text | Уникальный идентификатор (например: service_branding) |
| `value` | Long Text | Содержание (описание, цена, процесс) |
| `category` | Single Line Text | Категория (services, pricing, process, faq, team) |
| `active` | Checkbox | Активна ли запись (по умолчанию true) |

## Шаг 3: Как обновлять информацию в NocoBase

### Для редактирования существующей записи:

1. Откройте таблицу CompanyInfo
2. Найдите запись которую нужно отредактировать
3. Кликните на поле `value` чтобы отредактировать текст
4. Сохранится автоматически

### Для добавления новой записи:

1. Нажмите кнопку **"+ Add Record"** внизу таблицы
2. Заполните поля:
   - `key`: уникальный идентификатор (example_key)
   - `value`: содержание текста
   - `category`: выберите категорию из существующих
   - `active`: поставьте галочку если запись активна
3. Запись сохранится автоматически

### Для отключения записи (без удаления):

1. Найдите запись
2. Кликните на поле `active`
3. Уберите галочку
4. Чат больше не будет использовать эту информацию

### Для удаления записи:

1. Найдите запись
2. Кликните на кнопку удаления (X) слева от строки
3. Подтвердите удаление

## Как чат использует эту информацию

**Система работает так:**

1. Клиент пишет вопрос в чат
2. Чат загружает ВСЕ активные записи из CompanyInfo
3. Система добавляет эту информацию в контекст AI
4. AI отвечает, используя информацию из таблицы

**Примеры:**
- Вопрос: "Сколько стоит дизайн?"
  → Чат найдет в таблице все записи с category=pricing и даст точный ответ

- Вопрос: "Какой ваш процесс работы?"
  → Чат найдет все шаги процесса и объяснит

- Вопрос: "Как часто мы будем общаться?"
  → Чат найдет в FAQ и ответит на вопрос

## Рекомендации

✅ **Что добавлять:**
- Описания услуг
- Цены и пакеты
- Процесс работы
- FAQ (часто задаваемые вопросы)
- Информацию о команде
- Примеры работ (ссылки)
- Гарантии и warranty

❌ **Что НЕ добавлять:**
- Внутреннюю информацию (зарплаты, внутренние процессы)
- Контакты сотрудников (только общие контакты)
- Конфиденциальные данные
- Информацию о внутренних проблемах

## Синхронизация с чатом

Чат автоматически загружает данные из таблицы при **каждом вопросе клиента**.

⚠️ **Важно:** Если вы отредактируете таблицу, чат сразу же начнет использовать новую информацию. Обновление происходит в реальном времени.

## Помощь

Если чат не отвечает корректно на вопрос о услугах/ценах:

1. Проверьте, что запись в таблице имеет `active: true`
2. Убедитесь, что `category` правильно указана
3. Проверьте, что значение в `value` достаточно подробное
4. Попробуйте переформулировать вопрос в чате
